## AI-assisted writing

Set up your AI coding tool to work seamlessly with Mintlify:

```bash
npx skills add https://mintlify.com/docs
```

This installs Mintlify's documentation skill for AI tools like Claude Code, Cursor, and Windsurf. The skill includes component reference, writing standards, and workflow guidance.

<Tip>
  See the [AI tools guides](/ai-tools) for tool-specific setup instructions.
</Tip>
