## What is Mintlify?

Mintlify is a modern documentation platform that transforms MDX files into beautiful, interactive documentation sites. Built for developers and technical teams, it combines powerful features with an intuitive editing experience.

## Key Features

### Write with MDX

Create engaging documentation with Markdown enhanced by React components. Add interactive elements, custom layouts, and dynamic content without leaving your MDX files.

<CodeGroup>

```mdx Example.mdx
---
title: "My Page"
description: "A great page"
---

## Welcome

Use **Markdown** and React components together.

<Tip>
  This is a tip component!
</Tip>
```

```json docs.json
{
  "name": "My Docs",
  "colors": {
    "primary": "#16A34A",
    "light": "#07C983",
    "dark": "#15803D"
  }
}
```

</CodeGroup>

### Interactive Components

Mintlify provides dozens of built-in components to make your docs more engaging and easier to navigate.

<AccordionGroup>
  <Accordion title="Navigation Components" icon="compass">
    - **Cards & CardGroups**: Highlight key features or links
    - **Tabs**: Organize related content
    - **Steps**: Guide users through processes
    - **Accordions**: Collapse detailed information
  </Accordion>

  <Accordion title="Code Components" icon="code">
    - **CodeGroup**: Show code in multiple languages
    - **Code Blocks**: Syntax highlighting for 100+ languages
    - **Inline Code**: Highlight code within text
    - **API Playground**: Interactive API testing
  </Accordion>

  <Accordion title="Callout Components" icon="message">
    - **Note**: General information
    - **Tip**: Helpful suggestions
    - **Warning**: Important cautions
    - **Info**: Additional context
  </Accordion>

  <Accordion title="Media Components" icon="image">
    - **Frame**: Styled image containers
    - **Images**: Responsive image support
    - **Videos**: Embed videos from any source
    - **Icons**: Thousands of icons available
  </Accordion>
</AccordionGroup>

## Production-Ready Features

<Tip>
  Mintlify handles hosting, deployment, SSL, and CDN automatically. You just push to Git and your docs are live.
</Tip>

- **Automatic Deployments**: Push to GitHub and deploy instantly
- **Global CDN**: Fast loading times worldwide
- **SEO Optimized**: Built-in meta tags and sitemaps
- **Analytics Ready**: Track pageviews and user behavior
- **Search**: Powerful built-in search with keyboard shortcuts
- **Dark Mode**: Automatic dark mode support
- **Mobile Responsive**: Perfect on any device
- **Version Control**: Git-based workflow for tracking changes
