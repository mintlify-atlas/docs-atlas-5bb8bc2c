Every Mintlify site requires a `docs.json` file that controls your documentation's look, feel, and functionality. This configuration file is the central hub for customizing your site's theme, colors, branding, navigation, and more.

<Note>
The `docs.json` file should be placed in the root directory of your documentation project. Changes to this file require restarting your dev server.
</Note>

## Core Configuration

### Project Name and Theme

The most basic configuration includes your project name and theme selection:

```json docs.json
{
  "name": "Mint Starter Kit",
  "theme": "mint"
}
```

The `name` property sets your project's global title, appearing in the browser tab and throughout your documentation.

## Branding and Visual Identity

<Accordion title="Colors and Theme Customization">

Customize your documentation's color scheme using the `colors` object. Mintlify supports different colors for light and dark modes:

```json docs.json
{
  "colors": {
    "primary": "#16A34A",
    "light": "#07C983",
    "dark": "#15803D",
    "background": {
      "light": "#ffffff",
      "dark": "#0f172a"
    }
  }
}
```

**Color Properties:**
- `primary` - Main accent color for highlighted content, section headers, and links in light mode
- `light` - Primary color for dark mode UI elements
- `dark` - Color for important buttons and CTAs
- `background` - Custom background colors for both modes (optional)

<Tip>
Use colors that match your brand identity and ensure sufficient contrast for readability in both light and dark modes.
</Tip>

</Accordion>

<Accordion title="Logo Configuration">

Configure your logo to support both light and dark themes:

```json docs.json
{
  "logo": {
    "light": "/logo/light.svg",
    "dark": "/logo/dark.svg",
    "href": "/"
  }
}
```

**Logo Options:**
- Use a single string path for one logo: `"logo": "/logo.svg"`
- Use an object with `light` and `dark` properties for theme-specific logos
- Add `href` to customize where clicking the logo navigates (defaults to `/`)

Place your logo files in the `public` folder of your documentation project.

</Accordion>

<Accordion title="Favicon">

Set your site's favicon using a relative path:

```json docs.json
{
  "favicon": "/favicon.svg"
}
```

Supported formats include `.svg`, `.png`, and `.ico`. SVG files are recommended for better scalability.

</Accordion>

## Navigation Bar

### Top Navigation Links

Add links to your navigation bar using the `navbar` configuration:

```json docs.json
{
  "navbar": {
    "links": [
      {
        "label": "Support",
        "href": "mailto:hi@mintlify.com"
      }
    ],
    "primary": {
      "type": "button",
      "label": "Dashboard",
      "href": "https://dashboard.mintlify.com"
    }
  }
}
```

**Navbar Structure:**
- `links` - Array of secondary navigation links (appear as text links)
- `primary` - Call-to-action button with prominent styling

### Global Anchors

Create quick access links that appear in your navigation sidebar:

```json docs.json
{
  "navigation": {
    "global": {
      "anchors": [
        {
          "anchor": "Documentation",
          "href": "https://mintlify.com/docs",
          "icon": "book-open-cover"
        },
        {
          "anchor": "Blog",
          "href": "https://mintlify.com/blog",
          "icon": "newspaper"
        }
      ]
    }
  }
}
```

Anchors support Font Awesome icons and can link to both internal pages and external URLs.

## Footer Configuration

### Social Media Links

Add social media links to your footer:

```json docs.json
{
  "footer": {
    "socials": {
      "x": "https://x.com/mintlify",
      "github": "https://github.com/mintlify",
      "linkedin": "https://linkedin.com/company/mintlify"
    }
  }
}
```

**Supported Platforms:**
- `website` - Your main website
- `x` - X (Twitter)
- `github` - GitHub
- `linkedin` - LinkedIn
- `discord` - Discord
- `slack` - Slack
- `facebook` - Facebook
- `instagram` - Instagram
- `hacker-news` - Hacker News

## Advanced Features

<Accordion title="Dark Mode Toggle">

Customize or disable the dark mode toggle:

<CodeGroup>
```json Default Behavior
{
  "modeToggle": {
    "default": "dark"
  }
}
```

```json Hide Toggle (Force Dark Mode)
{
  "modeToggle": {
    "default": "dark",
    "isHidden": true
  }
}
```

```json Hide Toggle (Force Light Mode)
{
  "modeToggle": {
    "default": "light",
    "isHidden": true
  }
}
```
</CodeGroup>

When not set, Mintlify defaults to the user's operating system preference.

</Accordion>

<Accordion title="Contextual Actions">

Enable contextual actions that appear when users select text:

```json docs.json
{
  "contextual": {
    "options": [
      "copy",
      "view",
      "chatgpt",
      "claude",
      "perplexity",
      "mcp",
      "cursor",
      "vscode"
    ]
  }
}
```

These actions allow users to copy text, open it in various AI tools, or their code editor.

</Accordion>

<Accordion title="Feedback Buttons">

Enable user feedback options:

```json docs.json
{
  "feedback": {
    "suggestEdit": true,
    "raiseIssue": true
  }
}
```

- `suggestEdit` - Adds a button for users to suggest edits via pull requests
- `raiseIssue` - Adds a button to raise issues about the documentation

</Accordion>

<Accordion title="API Configuration">

Configure API documentation settings:

```json docs.json
{
  "api": {
    "baseUrl": "https://api.example.com",
    "auth": {
      "method": "bearer",
      "name": "Authorization"
    },
    "playground": {
      "mode": "show"
    }
  },
  "openapi": "https://example.com/openapi.json"
}
```

**API Options:**
- `baseUrl` - Base URL for all API endpoints (can be an array for multiple options)
- `auth` - Authentication configuration (bearer, basic, or key)
- `playground.mode` - Controls API playground visibility (`show`, `simple`, or `hide`)
- `openapi` - Path or URL to your OpenAPI specification file

</Accordion>

## Versioning

Enable version selection for your documentation:

```json docs.json
{
  "versions": ["v2.0", "v1.0"]
}
```

<Warning>
Version management requires additional setup beyond just adding the `versions` array. Each version needs its own set of documentation files.
</Warning>

## Background Image

Add a custom background image to all pages:

```json docs.json
{
  "backgroundImage": "/images/background.png"
}
```

The background image appears behind your content on every page. Keep images subtle to maintain readability.

## Complete Example

Here's a complete `docs.json` configuration combining multiple features:

```json docs.json
{
  "$schema": "https://mintlify.com/docs.json",
  "name": "Mint Starter Kit",
  "theme": "mint",
  "colors": {
    "primary": "#16A34A",
    "light": "#07C983",
    "dark": "#15803D"
  },
  "logo": {
    "light": "/logo/light.svg",
    "dark": "/logo/dark.svg"
  },
  "favicon": "/favicon.svg",
  "navbar": {
    "links": [
      {
        "label": "Support",
        "href": "mailto:hi@mintlify.com"
      }
    ],
    "primary": {
      "type": "button",
      "label": "Dashboard",
      "href": "https://dashboard.mintlify.com"
    }
  },
  "footer": {
    "socials": {
      "x": "https://x.com/mintlify",
      "github": "https://github.com/mintlify",
      "linkedin": "https://linkedin.com/company/mintlify"
    }
  },
  "navigation": {
    "tabs": [
      {
        "tab": "Guides",
        "groups": [
          {
            "group": "Getting started",
            "pages": ["index", "quickstart"]
          }
        ]
      }
    ]
  }
}
```

<Tip>
Use the `$schema` property to enable autocomplete and validation in your code editor.
</Tip>
