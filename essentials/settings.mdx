Every Mintlify site needs a `docs.json` file with the core configuration settings. This file controls your site's branding, theme colors, navigation structure, API playground, and more.

## Basic Configuration

Start with these essential properties to get your documentation site up and running.

<AccordionGroup>
  <Accordion title="name - Project name" icon="tag">
    The name of your project. This appears as the global title across your documentation.

    ```json
    {
      "name": "Mint Starter Kit"
    }
    ```
  </Accordion>

  <Accordion title="logo - Brand logo" icon="image">
    Path to your logo image. You can use a single logo or provide separate logos for light and dark modes.

    <Tabs>
      <Tab title="Separate logos">
        ```json
        {
          "logo": {
            "light": "/logo/light.svg",
            "dark": "/logo/dark.svg",
            "href": "/"
          }
        }
        ```
      </Tab>
      <Tab title="Single logo">
        ```json
        {
          "logo": "/logo.svg"
        }
        ```
      </Tab>
    </Tabs>

    <Note>The `href` property controls where clicking the logo takes users. Defaults to `/` if not specified.</Note>
  </Accordion>

  <Accordion title="favicon - Site icon" icon="browser">
    Path to the favicon that appears in browser tabs.

    ```json
    {
      "favicon": "/favicon.svg"
    }
    ```
  </Accordion>
</AccordionGroup>

## Theme Colors

Customize your documentation's color scheme to match your brand. All colors use hex codes.

```json
{
  "colors": {
    "primary": "#16A34A",
    "light": "#07C983",
    "dark": "#15803D",
    "background": {
      "light": "#FFFFFF",
      "dark": "#0A0A0A"
    }
  }
}
```

<Tip>The `primary` color is used for highlighted content, section headers, and accents in light mode. The `light` property sets the primary color for dark mode.</Tip>

### Color Properties

- **primary** - Main accent color for light mode (used for links, highlights, and UI accents)
- **light** - Primary accent color for dark mode
- **dark** - Color for important buttons and CTAs
- **background** - Custom background colors for both light and dark modes

## Navigation Bar

Add links and call-to-action buttons to your top navigation bar.

<CodeGroup>
```json Navbar with links
{
  "navbar": {
    "links": [
      {
        "label": "Support",
        "href": "mailto:hi@mintlify.com"
      }
    ]
  }
}
```

```json Navbar with CTA button
{
  "navbar": {
    "links": [
      {
        "label": "Support",
        "href": "mailto:hi@mintlify.com"
      }
    ],
    "primary": {
      "type": "button",
      "label": "Dashboard",
      "href": "https://dashboard.mintlify.com"
    }
  }
}
```

```json GitHub integration
{
  "navbar": {
    "primary": {
      "type": "github",
      "href": "https://github.com/mintlify/starter"
    }
  }
}
```
</CodeGroup>

<Note>When using `type: "github"`, Mintlify automatically displays your repository information including GitHub stars.</Note>

## Footer Configuration

Add social media links to your documentation footer.

```json
{
  "footer": {
    "socials": {
      "x": "https://x.com/mintlify",
      "github": "https://github.com/mintlify",
      "linkedin": "https://linkedin.com/company/mintlify"
    }
  }
}
```

**Supported platforms:** `website`, `facebook`, `x`, `discord`, `slack`, `github`, `linkedin`, `instagram`, `hacker-news`

## API Configuration

Configure API playground settings and authentication for your API reference pages.

<AccordionGroup>
  <Accordion title="Base URL" icon="link">
    Set the base URL for all API endpoints. You can provide multiple base URLs for different environments.

    ```json
    {
      "api": {
        "baseUrl": "https://api.example.com"
      }
    }
    ```

    <Tip>For multiple environments, use an array: `"baseUrl": ["https://api.example.com", "https://api-staging.example.com"]`</Tip>
  </Accordion>

  <Accordion title="Authentication" icon="key">
    Configure the authentication method for your API playground.

    <Tabs>
      <Tab title="Bearer token">
        ```json
        {
          "api": {
            "auth": {
              "method": "bearer",
              "name": "Authorization",
              "inputPrefix": "Bearer"
            }
          }
        }
        ```
      </Tab>
      <Tab title="API key">
        ```json
        {
          "api": {
            "auth": {
              "method": "key",
              "name": "api_key"
            }
          }
        }
        ```
      </Tab>
      <Tab title="Basic auth">
        ```json
        {
          "api": {
            "auth": {
              "method": "basic",
              "name": "username:password"
            }
          }
        }
        ```
      </Tab>
    </Tabs>
  </Accordion>

  <Accordion title="Playground mode" icon="play">
    Control how the API playground displays on your pages.

    ```json
    {
      "api": {
        "playground": {
          "mode": "show"
        }
      }
    }
    ```

    **Available modes:**
    - `show` - Full interactive playground (default)
    - `simple` - Display endpoint only, no interactivity
    - `hide` - Hide the playground completely
  </Accordion>

  <Accordion title="OpenAPI specification" icon="file-code">
    Point to your OpenAPI specification file(s) to automatically generate API documentation.

    <CodeGroup>
    ```json Single spec
    {
      "openapi": "https://example.com/openapi.json"
    }
    ```

    ```json Local file
    {
      "openapi": "/openapi.json"
    }
    ```

    ```json Multiple specs
    {
      "openapi": [
        "https://example.com/openapi1.json",
        "/openapi2.json",
        "/openapi3.json"
      ]
    }
    ```
    </CodeGroup>
  </Accordion>
</AccordionGroup>

## Mode Toggle

Customize the dark mode toggle behavior for your documentation.

<CodeGroup>
```json Auto (system default)
{
  "modeToggle": {}
}
```

```json Force dark mode
{
  "modeToggle": {
    "default": "dark",
    "isHidden": true
  }
}
```

```json Force light mode
{
  "modeToggle": {
    "default": "light",
    "isHidden": true
  }
}
```

```json Default to dark
{
  "modeToggle": {
    "default": "dark"
  }
}
```
</CodeGroup>

<Warning>Setting `isHidden: true` removes the dark/light mode toggle from your documentation. Users won't be able to change modes.</Warning>

## Feedback Buttons

Enable feedback buttons to let users suggest edits or raise issues about your documentation.

```json
{
  "feedback": {
    "suggestEdit": true,
    "raiseIssue": true
  }
}
```

- **suggestEdit** - Adds a button that lets users suggest edits via pull requests
- **raiseIssue** - Adds a button that lets users raise issues on GitHub

## Versions

Show different versions of your documentation with a dropdown in the navigation bar.

```json
{
  "versions": ["v2.0", "v1.0"]
}
```

<Note>This creates a version picker that lets users switch between different documentation versions.</Note>

## Background Image

Add a custom background image that displays behind every page.

```json
{
  "backgroundImage": "/background.png"
}
```

<Tip>Check out examples at [Infisical](https://infisical.com/docs) and [FRPC](https://frpc.io) to see background images in action.</Tip>

## Complete Example

Here's a complete `docs.json` configuration using settings from the Mint Starter Kit:

```json
{
  "$schema": "https://mintlify.com/docs.json",
  "theme": "mint",
  "name": "Mint Starter Kit",
  "colors": {
    "primary": "#16A34A",
    "light": "#07C983",
    "dark": "#15803D"
  },
  "favicon": "/favicon.svg",
  "logo": {
    "light": "/logo/light.svg",
    "dark": "/logo/dark.svg"
  },
  "navbar": {
    "links": [
      {
        "label": "Support",
        "href": "mailto:hi@mintlify.com"
      }
    ],
    "primary": {
      "type": "button",
      "label": "Dashboard",
      "href": "https://dashboard.mintlify.com"
    }
  },
  "footer": {
    "socials": {
      "x": "https://x.com/mintlify",
      "github": "https://github.com/mintlify",
      "linkedin": "https://linkedin.com/company/mintlify"
    }
  }
}
```
