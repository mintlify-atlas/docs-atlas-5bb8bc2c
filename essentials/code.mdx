## Inline code

Wrap text in backticks to display it as inline code. Perfect for referencing variables, functions, or file names within sentences.

<Tip>
Use inline code for: variable names (`userName`), function calls (`fetchData()`), file paths (`src/index.js`), and terminal commands (`npm install`).
</Tip>

Include file names after the language tag to provide context:


</Note>

## CodeGroup component

Display multiple code examples side-by-side using tabs. Perfect for showing the same operation in different languages or frameworks.

<CodeGroup>

```javascript JavaScript
const response = await fetch('https://api.example.com/data');
const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get('https://api.example.com/data')
data = response.json()
print(data)
```

```ruby Ruby
require 'net/http'
require 'json'

uri = URI('https://api.example.com/data')
response = Net::HTTP.get(uri)
data = JSON.parse(response)
puts data
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    resp, _ := http.Get("https://api.example.com/data")
    var data map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&data)
    fmt.Println(data)
}
```

</CodeGroup>

### API endpoints

Document REST API calls with clear examples:

<CodeGroup>

```bash cURL
curl -X POST https://api.example.com/users \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "name": "Jane Doe",
    "email": "jane@example.com"
  }'
```

```javascript JavaScript
const response = await fetch('https://api.example.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_TOKEN'
  },
  body: JSON.stringify({
    name: 'Jane Doe',
    email: 'jane@example.com'
  })
});
```

```python Python
import requests

headers = {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_TOKEN'
}

data = {
    'name': 'Jane Doe',
    'email': 'jane@example.com'
}

response = requests.post(
    'https://api.example.com/users',
    headers=headers,
    json=data
)
```

</CodeGroup>

## Real-world example

Here's a complete example showing how to implement authentication:

<Tabs>
  <Tab title="Setup">
    First, install the required packages:
    
    ```bash
    npm install jsonwebtoken bcrypt
    ```
  </Tab>
  
  <Tab title="Implementation">
    <CodeGroup>
    
    ```javascript auth.js
    const jwt = require('jsonwebtoken');
    const bcrypt = require('bcrypt');
    
    async function login(email, password) {
      // Find user in database
      const user = await db.users.findOne({ email });
      
      // Verify password
      const isValid = await bcrypt.compare(password, user.passwordHash);
      
      if (!isValid) {
        throw new Error('Invalid credentials');
      }
      
      // Generate token
      const token = jwt.sign(
        { userId: user.id },
        process.env.JWT_SECRET,
        { expiresIn: '7d' }
      );
      
      return token;
    }
    ```
    
    ```typescript auth.ts
    import jwt from 'jsonwebtoken';
    import bcrypt from 'bcrypt';
    
    interface User {
      id: string;
      email: string;
      passwordHash: string;
    }
    
    async function login(email: string, password: string): Promise<string> {
      // Find user in database
      const user = await db.users.findOne({ email }) as User;
      
      // Verify password
      const isValid = await bcrypt.compare(password, user.passwordHash);
      
      if (!isValid) {
        throw new Error('Invalid credentials');
      }
      
      // Generate token
      const token = jwt.sign(
        { userId: user.id },
        process.env.JWT_SECRET!,
        { expiresIn: '7d' }
      );
      
      return token;
    }
    ```
    
    </CodeGroup>
  </Tab>
  
  <Tab title="Usage">
    Use the authentication function in your API routes:
    
    ```javascript
    app.post('/api/login', async (req, res) => {
      try {
        const { email, password } = req.body;
        const token = await login(email, password);
        res.json({ token });
      } catch (error) {
        res.status(401).json({ error: error.message });
      }
    });
    ```
  </Tab>
</Tabs>

<Warning>
Never commit sensitive data like API keys or passwords in code examples. Use environment variables or placeholders like `YOUR_TOKEN`.
</Warning>
