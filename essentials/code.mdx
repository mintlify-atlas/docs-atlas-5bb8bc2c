Mintlify provides powerful syntax highlighting for code blocks and supports inline code snippets.

## Inline code

To denote a `word` or `phrase` as code, enclose it in backticks (`).

```md
To denote a `word` or `phrase` as code, enclose it in backticks (`).
```

Use inline code for:
- Function names like `useState()` or `fetchData()`
- Variable names like `userName` or `API_KEY`
- File names like `config.json` or `app.tsx`
- Short commands like `npm install` or `git push`

## Code blocks

Use [fenced code blocks](https://www.markdownguide.org/extended-syntax/#fenced-code-blocks) by enclosing code in three backticks and follow the leading ticks with the programming language of your snippet to get syntax highlighting. Optionally, you can also write the name of your code after the programming language.

```java HelloWorld.java
class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

Mintlify supports syntax highlighting for all major programming languages:

<Accordion title="JavaScript/TypeScript">

<Accordion title="Python">

## CodeGroup

Use CodeGroup to display multiple code examples in tabs. This is perfect for showing the same operation in different languages or frameworks:

<CodeGroup>

```javascript Node.js
const response = await fetch('https://api.example.com/data', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({ key: 'value' })
});

const data = await response.json();
```

```python Python
import requests

headers = {
    'Content-Type': 'application/json',
    'Authorization': f'Bearer {token}'
}

response = requests.post(
    'https://api.example.com/data',
    headers=headers,
    json={'key': 'value'}
)

data = response.json()
```

```bash cURL
curl -X POST https://api.example.com/data \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"key": "value"}'
```

</CodeGroup>

Here's how to create a CodeGroup:

````md

````

<Tip>
CodeGroup automatically detects the language from the code fence and creates a tab for each code block. The text after the language name becomes the tab label.
</Tip>

## File names and line highlighting

Add a file name after the language to display it above your code block:

```typescript users.service.ts
export class UsersService {
  async findUser(id: string) {
    return await this.db.user.findUnique({
      where: { id }
    });
  }
}
```

## Shell commands

For terminal commands and shell scripts, use `bash`, `sh`, or `shell`:

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
