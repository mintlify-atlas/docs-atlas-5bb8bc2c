## Image basics

Images help clarify concepts, show UI elements, and make documentation more engaging. Mintlify supports multiple ways to add images.

<Tabs>
  <Tab title="Markdown syntax">
    Use standard Markdown syntax for simple images:
    
    ```md
    ![Alt text](/images/screenshot.png)
    ```
    
    The alt text improves accessibility and SEO.
  </Tab>
  
  <Tab title="HTML syntax">
    Use HTML `<img>` tags for more control:
    
    ```html
    <img 
      src="/images/screenshot.png" 
      alt="Dashboard overview"
      style={{ borderRadius: '0.5rem' }}
    />
    ```
    
    This allows custom styling, dimensions, and attributes.
  </Tab>
</Tabs>

<Note>
Image file sizes should be under 5MB for optimal loading performance. For larger files, use external hosting services like Cloudinary or AWS S3.
</Note>

## Image organization

Keep your documentation images organized with a clear folder structure.

<Steps>
  <Step title="Create an images directory">
    Store all images in an `/images` folder at the root of your docs:
    
    ```
    docs/
    ├── images/
    │   ├── getting-started/
    │   │   ├── setup.png
    │   │   └── dashboard.png
    │   ├── api/
    │   │   └── endpoint.png
    │   └── logo.svg
    └── index.mdx
    ```
  </Step>
  
  <Step title="Use descriptive names">
    Name files clearly: `dashboard-overview.png` instead of `img1.png`
  </Step>
  
  <Step title="Reference with absolute paths">
    Always use root-relative paths starting with `/`:
    
    ```md
    ![Setup screen](/images/getting-started/setup.png)
    ```
  </Step>
</Steps>

## Image sizing

Control image dimensions for consistent layouts.

<Accordion title="Inline styling">

Use the `style` attribute for custom sizing:

```html
<img 
  src="/images/icon.png"
  alt="Icon"
  style={{ width: '200px', height: '200px' }}
/>
```

</Accordion>

<Accordion title="Width and height attributes">

Use standard HTML attributes:

```html
<img 
  src="/images/banner.png"
  alt="Banner"
  width="800"
  height="400"
/>
```

</Accordion>

<Accordion title="Responsive images">

Make images responsive with max-width:

```html
<img 
  src="/images/diagram.png"
  alt="Architecture diagram"
  style={{ maxWidth: '100%', height: 'auto' }}
/>
```

</Accordion>

Embed Loom recordings for walkthroughs:

```html
<iframe
  src="https://www.loom.com/embed/VIDEO_ID"
  frameBorder="0"
  webkitallowfullscreen

></iframe>
```

<Tip>
Videos are perfect for tutorials, product demos, and complex explanations that benefit from visual walkthroughs.
</Tip>

## Other embeds

Mintlify supports any HTML element, giving you unlimited flexibility.

<AccordionGroup>
  <Accordion icon="chart-line" title="Interactive charts">
    Embed interactive visualizations from tools like Observable, CodePen, or custom JavaScript:
    
    ```html
    <iframe src="https://observablehq.com/embed/@user/notebook"></iframe>
    ```
  </Accordion>
  
  <Accordion icon="file-pdf" title="PDF documents">
    Embed PDF files directly:
    
    ```html
    <iframe src="/documents/whitepaper.pdf" width="100%" height="600px"></iframe>
    ```
  </Accordion>
  
  <Accordion icon="window" title="Live demos">
    Embed CodeSandbox or StackBlitz for interactive code examples:
    
    ```html
    <iframe 
      src="https://codesandbox.io/embed/example"
      style={{ width: '100%', height: '500px', border: 0, borderRadius: '0.5rem' }}
    ></iframe>
    ```
  </Accordion>
  
  <Accordion icon="twitter" title="Social media">
    Embed tweets, LinkedIn posts, or other social content using their embed codes.
  </Accordion>
</AccordionGroup>

## Accessibility best practices

Make your visual content accessible to all users:

<Steps>
  <Step title="Write descriptive alt text">
    Describe what the image shows, not just "screenshot" or "image"
    
    ```html
    <!-- Good -->
    <img src="/dashboard.png" alt="Analytics dashboard showing user growth over 6 months" />
    
    <!-- Bad -->
    <img src="/dashboard.png" alt="screenshot" />
    ```
  </Step>
  
  <Step title="Don't rely on images alone">
    Always provide text explanations alongside images. Never put critical information only in images.
  </Step>
  
  <Step title="Use sufficient contrast">
    Ensure text in images has good contrast ratios for readability.
  </Step>
  
  <Step title="Provide transcripts for videos">
    Include text transcripts or captions for video content.
  </Step>
</Steps>
