## What is MDX?

MDX combines the simplicity of Markdown with the power of JSX, allowing you to use interactive components directly in your documentation. Mintlify extends MDX with beautiful pre-built components that make your docs stand out.

<Note>
MDX files have a `.mdx` extension and support both standard Markdown syntax and React components.
</Note>

## Text formatting

Format text using simple Markdown syntax or HTML tags for more advanced styling.

### Basic formatting

| Style         | Syntax            | Result          |
| ------------- | ----------------- | --------------- |
| Bold          | `**bold**`        | **bold**        |
| Italic        | `_italic_`        | _italic_        |
| Strikethrough | `~strikethrough~` | ~strikethrough~ |
| Inline code   | `` `code` ``      | `code`          |

Combine styles for emphasis: `**_bold and italic_**` renders as **_bold and italic_**.

### Superscript and subscript

Use HTML tags for scientific notation and mathematical expressions:

| Style       | Syntax                   | Result                 |
| ----------- | ------------------------ | ---------------------- |
| Superscript | `<sup>superscript</sup>` | <sup>superscript</sup> |
| Subscript   | `<sub>subscript</sub>`   | <sub>subscript</sub>   |

Example: H<sub>2</sub>O or E = mc<sup>2</sup>

## Links

<Steps>
  <Step title="External links">
    Link to external sites using standard Markdown syntax:
    
    ```md
    [Visit Mintlify](https://mintlify.com)
    ```
    
    Result: [Visit Mintlify](https://mintlify.com)
  </Step>
  
  <Step title="Internal links">
    Use root-relative paths for internal documentation links:
    
    ```md
    [Code blocks](/essentials/code)
    ```
    
    This ensures Mintlify can optimize page loading and navigation.
  </Step>
  
  <Step title="Avoid relative paths">
    While `../code` works, it's slower because Mintlify can't pre-optimize these links.
  </Step>
</Steps>

## Lists

### Unordered lists

Create bullet lists with `-`, `*`, or `+`:

```md
- First item
- Second item
  - Nested item
  - Another nested item
- Third item
```

Result:
- First item
- Second item
  - Nested item
  - Another nested item
- Third item

### Ordered lists

Use numbers for sequential steps:

```md
1. First step
2. Second step
3. Third step
```

Result:
1. First step
2. Second step
3. Third step
