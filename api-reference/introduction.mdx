## Base URL

All API requests should be made to:

```
http://sandbox.mintlify.com
```

## Authentication

All API endpoints require authentication using Bearer tokens. Include your API token in the Authorization header of each request:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Warning>
  Keep your API tokens secure and never share them in public repositories or client-side code.
</Warning>

### Security Configuration

The API uses Bearer authentication as defined in the OpenAPI specification:

```json
"security": [
  {
    "bearerAuth": []
  }
]
```

## API Structure

The Plant Store API is organized around REST principles. It uses standard HTTP methods, accepts JSON request bodies, and returns JSON-encoded responses.

## Response Format

All responses are returned in JSON format with appropriate HTTP status codes:

- `200` - Successful request
- `204` - Successful request with no content
- `400` - Bad request or unexpected error
- `401` - Unauthorized (invalid or missing token)
- `404` - Resource not found

### Error Handling

When an error occurs, the API returns a JSON object with error details:

```json
{
  "error": 400,
  "message": "Descriptive error message"
}
```

<Tip>
  Always check the HTTP status code and handle errors appropriately in your application.
</Tip>
