## Overview

The `DELETE /plants/{id}` endpoint removes a single plant from the store based on the ID supplied. This operation is permanent and cannot be undone.

<Warning>
This is a destructive operation. Once a plant is deleted, it cannot be recovered. Always confirm the plant ID before deletion.
</Warning>

## Request

### Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the plant to delete. This ID is returned when creating a plant or can be retrieved from the GET /plants endpoint.
  
  **Example:** `42`
</ParamField>

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

## Response

### Success Response (204 No Content)

A successful deletion returns a `204 No Content` status with an empty response body. This indicates the plant was successfully removed from the store.

### Error Responses

<ResponseField name="error" type="integer">
  Error code indicating the type of error
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable error message describing what went wrong
</ResponseField>

const plantId = 42;

const response = await fetch(`http://sandbox.mintlify.com/plants/${plantId}`, {

```python Python
import requests

plant_id = 42
url = f"http://sandbox.mintlify.com/plants/{plant_id}"
headers = {
    "Authorization": "Bearer YOUR_ACCESS_TOKEN"
}

response = requests.delete(url, headers=headers)

if response.status_code == 204:
    print("Plant deleted successfully")
else:
    print(f"Error: {response.json()}")
```

```go Go
package main

import (
    "fmt"
    "net/http"
)

func main() {
    plantID := 42
    url := fmt.Sprintf("http://sandbox.mintlify.com/plants/%d", plantID)
    
    req, _ := http.NewRequest("DELETE", url, nil)
    req.Header.Add("Authorization", "Bearer YOUR_ACCESS_TOKEN")
    
    client := &http.Client{}
    resp, err := client.Do(req)
    if err != nil {
        panic(err)
    }
    defer resp.Body.Close()
    
    if resp.StatusCode == 204 {
        fmt.Println("Plant deleted successfully")
    } else {
        fmt.Printf("Error: %d\n", resp.StatusCode)
    }
}
```

## Best Practices

<AccordionGroup>
  <Accordion title="Verify plant exists before deletion">
    Always check if a plant exists before attempting to delete it to provide better user feedback.
    
    ```javascript
    async function deletePlantSafely(plantId) {
      // First, verify the plant exists
      const getResponse = await fetch(
        'http://sandbox.mintlify.com/plants',
        {
          headers: { 'Authorization': `Bearer ${token}` }
        }
      );
      
      const plants = await getResponse.json();
      const plant = plants.find(p => p.id === plantId);
      
      if (!plant) {
        throw new Error(`Plant with ID ${plantId} does not exist`);
      }
      
      // Proceed with deletion
      const deleteResponse = await fetch(
        `http://sandbox.mintlify.com/plants/${plantId}`,
        {
          method: 'DELETE',
          headers: { 'Authorization': `Bearer ${token}` }
        }
      );
      
      return deleteResponse.status === 204;
    }
    ```
  </Accordion>
  
  <Accordion title="Implement confirmation prompts">
    Always ask users to confirm deletion actions to prevent accidental data loss.
    
    ```javascript
    async function deleteWithConfirmation(plantId, plantName) {
      const confirmed = window.confirm(
        `Are you sure you want to delete "${plantName}"? This action cannot be undone.`
      );
      
      if (!confirmed) {
        return false;
      }
      
      try {
        const response = await fetch(
          `http://sandbox.mintlify.com/plants/${plantId}`,
          {
            method: 'DELETE',
            headers: { 'Authorization': `Bearer ${token}` }
          }
        );
        
        if (response.status === 204) {
          console.log(`Successfully deleted ${plantName}`);
          return true;
        }
      } catch (error) {
        console.error('Deletion failed:', error);
        return false;
      }
    }
    ```
  </Accordion>
  
  <Accordion title="Handle errors gracefully">
    Implement proper error handling for common scenarios like network failures and authentication issues.
    
    ```javascript
    async function deletePlant(plantId) {
      try {
        const response = await fetch(
          `http://sandbox.mintlify.com/plants/${plantId}`,
          {
            method: 'DELETE',
            headers: { 'Authorization': `Bearer ${token}` }
          }
        );
        
        if (response.status === 204) {
          return { success: true };
        }
        
        if (response.status === 404) {
          return { 
            success: false, 
            error: 'Plant not found. It may have already been deleted.' 
          };
        }
        
        if (response.status === 403) {
          return { 
            success: false, 
            error: 'You do not have permission to delete this plant.' 
          };
        }
        
        const errorData = await response.json();
        return { 
          success: false, 
          error: errorData.message || 'Unknown error occurred' 
        };
      } catch (error) {
        return { 
          success: false, 
          error: 'Network error. Please check your connection.' 
        };
      }
    }
    ```
  </Accordion>
  
  <Accordion title="Consider soft deletes for critical data">
    For important data, consider implementing soft deletes (marking as deleted) rather than permanent deletion.
    
    ```javascript
    // Alternative: Implement soft delete using an update endpoint
    async function softDeletePlant(plantId) {
      // If your API supports it, mark as deleted instead of removing
      const response = await fetch(
        `http://sandbox.mintlify.com/plants/${plantId}`,

          method: 'PATCH',

            'Authorization': `Bearer ${token}`,
            'Content-Type': 'application/json'
          },
          body: JSON.stringify({
            deleted: true,
            deletedAt: new Date().toISOString()
          })
        }
      );
      
      return response.ok;
    }
    ```
  </Accordion>

## Bulk Deletion

For deleting multiple plants, implement proper batching and error handling:

```javascript
async function bulkDeletePlants(plantIds) {
  const results = {
    successful: [],
    failed: []
  };
  
  for (const id of plantIds) {
    try {
      const response = await fetch(
        `http://sandbox.mintlify.com/plants/${id}`,
        {
          method: 'DELETE',
          headers: { 'Authorization': `Bearer ${token}` }
        }
      );
      
      if (response.status === 204) {
        results.successful.push(id);
      } else {
        results.failed.push({ id, reason: 'Deletion failed' });
      }
    } catch (error) {
      results.failed.push({ id, reason: error.message });
    }
    
    // Small delay to respect rate limits
    await new Promise(resolve => setTimeout(resolve, 100));
  }
  
  console.log(`Deleted ${results.successful.length} plants`);
  console.log(`Failed to delete ${results.failed.length} plants`);
  
  return results;
}
```

<Note>
The DELETE endpoint returns an empty response body with a 204 status code. Make sure your code handles this correctly and doesn't expect JSON data in the response.
</Note>
