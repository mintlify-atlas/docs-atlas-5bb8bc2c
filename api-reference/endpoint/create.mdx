## Overview

The `POST /plants` endpoint creates a new plant in the store. This endpoint accepts a JSON payload containing the plant details and returns the created plant object with its assigned ID.

<Note>
This endpoint requires authentication using a Bearer token in the Authorization header.
</Note>

## Request

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

<ParamField header="Content-Type" type="string" required>
  Must be set to `application/json`
</ParamField>

### Body Parameters

<ParamField body="name" type="string" required>
  The name of the plant. This field is required and cannot be empty.
  
  **Example values:**
  - `"Monstera Deliciosa"`
  - `"Snake Plant"`
  - `"Peace Lily"`
</ParamField>

<ParamField body="tag" type="string" optional>
  Optional tag to specify the type or category of the plant. Use tags to organize and filter plants.
  
  **Example values:**
  - `"tropical"`
  - `"succulent"`
  - `"flowering"`
  - `"low-maintenance"`
</ParamField>

## Response

<ResponseField name="id" type="integer">
  Unique identifier assigned to the newly created plant
</ResponseField>

<ResponseField name="name" type="string">
  The name of the plant as provided in the request
</ResponseField>

<ResponseField name="tag" type="string">
  The tag associated with the plant, if provided
</ResponseField>

## Examples

<CodeGroup>

```bash cURL
curl -X POST "http://sandbox.mintlify.com/plants" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Monstera Deliciosa",
    "tag": "tropical"
  }'
```

```javascript JavaScript
const plantData = {
  name: "Monstera Deliciosa",
  tag: "tropical"
};

const response = await fetch('http://sandbox.mintlify.com/plants', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_ACCESS_TOKEN',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(plantData)
});

const newPlant = await response.json();
console.log('Created plant:', newPlant);
```

```python Python
import requests

url = "http://sandbox.mintlify.com/plants"
headers = {
    "Authorization": "Bearer YOUR_ACCESS_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "name": "Monstera Deliciosa",
    "tag": "tropical"
}

response = requests.post(url, headers=headers, json=data)
plant = response.json()
print(f"Created plant: {plant}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "io"
    "net/http"
)

type Plant struct {
    Name string `json:"name"`
    Tag  string `json:"tag,omitempty"`
}

func main() {
    plant := Plant{
        Name: "Monstera Deliciosa",
        Tag:  "tropical",
    }
    
    jsonData, _ := json.Marshal(plant)
    
    req, _ := http.NewRequest(
        "POST",
        "http://sandbox.mintlify.com/plants",
        bytes.NewBuffer(jsonData),
    )
    req.Header.Add("Authorization", "Bearer YOUR_ACCESS_TOKEN")
    req.Header.Add("Content-Type", "application/json")
    
    client := &http.Client{}
    resp, err := client.Do(req)
    if err != nil {
        panic(err)
    }
    defer resp.Body.Close()
    
    body, _ := io.ReadAll(resp.Body)
    fmt.Println(string(body))
}
```

```ruby Ruby
require 'net/http'
require 'json'

uri = URI('http://sandbox.mintlify.com/plants')
plant_data = {
  name: "Monstera Deliciosa",
  tag: "tropical"
}

http = Net::HTTP.new(uri.host, uri.port)
request = Net::HTTP::Post.new(uri.path)
request['Authorization'] = 'Bearer YOUR_ACCESS_TOKEN'
request['Content-Type'] = 'application/json'
request.body = plant_data.to_json

response = http.request(request)
plant = JSON.parse(response.body)
puts "Created plant: #{plant}"
```

```json 200 OK
{

  "tag": "tropical"
}
```

### Error Response

```json 400 Bad Request

  "error": 400,
  "message": "Missing required field: name"
}
```

## Best Practices

<Tip>
Save the returned `id` from the response - you'll need it for future operations like updating or deleting the plant.
</Tip>

<Warning>
Ensure your authentication token has write permissions. Read-only tokens will result in a 403 Forbidden error.
</Warning>
