## Overview

The `GET /plants` endpoint returns all plants from the system that the authenticated user has access to. This endpoint supports pagination through the `limit` parameter and returns a JSON array of plant objects.

<Note>
This endpoint requires authentication using a Bearer token in the Authorization header.
</Note>

## Request

### Query Parameters

<ParamField query="limit" type="integer" optional>
  The maximum number of results to return. Use this parameter to implement pagination and control the size of the response payload.
  
  **Example values:**
  - `10` - Returns up to 10 plants
  - `50` - Returns up to 50 plants
  - `100` - Returns up to 100 plants
</ParamField>

### Headers

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_ACCESS_TOKEN`
</ParamField>

## Response

<ResponseField name="plants" type="array">
  An array of plant objects representing all plants the user has access to.
  
  <Expandable title="Plant Object">
    <ResponseField name="id" type="integer">
      Unique identifier for the plant
    </ResponseField>
    
    <ResponseField name="name" type="string">
      The name of the plant (required)
    </ResponseField>
    
    <ResponseField name="tag" type="string">
      Optional tag to specify the plant type or category
    </ResponseField>
  </Expandable>
</ResponseField>

```bash cURL

  -H "Content-Type: application/json"
```

```javascript JavaScript

  method: 'GET',
```

```python Python
import requests

url = "http://sandbox.mintlify.com/plants"
headers = {
    "Authorization": "Bearer YOUR_ACCESS_TOKEN",
    "Content-Type": "application/json"
}
params = {
    "limit": 10
}

response = requests.get(url, headers=headers, params=params)
plants = response.json()
print(plants)
```


## Best Practices

<AccordionGroup>
  <Accordion title="Implement pagination for large datasets">
    Always use the `limit` parameter to control response size. Start with a reasonable limit (e.g., 20-50 items) and implement pagination in your UI.
    
    ```javascript
    // Fetch plants in batches
    async function fetchPlantsBatch(limit = 20) {
      const response = await fetch(
        `http://sandbox.mintlify.com/plants?limit=${limit}`,
        {
          headers: {
            'Authorization': `Bearer ${token}`
          }
        }
      );
      return response.json();
    }
    ```
  </Accordion>
  
  <Accordion title="Cache responses to reduce API calls">
    Cache plant data locally and refresh periodically to minimize unnecessary API requests and improve performance.
    
    ```javascript
    const CACHE_DURATION = 5 * 60 * 1000; // 5 minutes
    let cachedPlants = null;
    let cacheTimestamp = null;
    
    async function getCachedPlants() {
      const now = Date.now();
      if (cachedPlants && (now - cacheTimestamp) < CACHE_DURATION) {
        return cachedPlants;
      }
      
      cachedPlants = await fetchPlants();
      cacheTimestamp = now;
      return cachedPlants;
    }
    ```
  </Accordion>
  
  <Accordion title="Handle errors gracefully">
    Implement proper error handling for network failures, authentication errors, and invalid responses.
    
    ```javascript
    try {
      const response = await fetch('http://sandbox.mintlify.com/plants', {
        headers: { 'Authorization': `Bearer ${token}` }
      });
      
      if (!response.ok) {
        throw new Error(`HTTP ${response.status}: ${response.statusText}`);
      }
      
      const plants = await response.json();
      return plants;
    } catch (error) {
      console.error('Failed to fetch plants:', error);
      // Show user-friendly error message
    }
    ```
  </Accordion>
  
  <Accordion title="Secure your authentication tokens">
    Never expose Bearer tokens in client-side code or logs. Store tokens securely and use environment variables for sensitive credentials.
  </Accordion>
</AccordionGroup>

<Warning>
Rate limiting applies to this endpoint. Excessive requests may result in temporary throttling. Implement caching and respect rate limits to ensure reliable service.
</Warning>
